Training-Time Affinity → Inference-Time OCS Pre-Configuration

Pseudocode for capturing expert co-activation patterns and pre-wiring OCS circuits

Phase 1 — Capture: Build Co-Activation Graph
// Initialize tracker tracker ← ExpertAffinityTracker(num_experts) // Feed router outputs from any source (HF / MLX / synthetic) for each token t in training_corpus: expert_ids ← router(t) // top-K expert assignments tracker.record_routing(expert_ids) // tracker.co_activation_counts[eᵢ][eⱼ] — how often eᵢ and eⱼ fire together // Normalized: P(eⱼ co-selected | eᵢ selected) ∈ [0, 1] affinity[eᵢ][eⱼ] ← co_activation[eᵢ][eⱼ] / usage[eᵢ]
Phase 2 — Plan: Expert Pairs → Rank Pairs → Ranked Circuit List
function compute_circuit_plan(affinity, experts_per_rank, max_circuits): scores ← {} // (src_rank, dst_rank) → score for each expert pair (eₐ, e_b): rankₐ ← eₐ // experts_per_rank rank_b ← e_b // experts_per_rank if rankₐ ≠ rank_b: scores[(rankₐ, rank_b)] ← max(scores[(rankₐ, rank_b)], affinity[eₐ][e_b]) ranked ← sort scores by value descending return ranked[0 : max_circuits] // priority-ordered circuit plan // Serialized as preset_plan.json via preconfig.py export_plan(compute_circuit_plan(...))
Phase 3 — Inference: Pre-Establish, Zero Reconfig
// At inference startup (ocs_preset scheduler mode) plan ← load_plan("preset_plan.json") ocs_pool.pre_config(plan) // batch-establish top-N circuits // Inference loop — NO runtime circuit switching for each micro-batch b: route(b) → scatter(b) → compute(b) → gather(b) → combine(b) ↑ all communication over pre-established OCS paths // No pre_establish_circuits() calls — reconfig latency eliminated entirely
